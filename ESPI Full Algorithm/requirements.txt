# ==============================================================================
# Zadig driver step (Windows only) — required for the signal generator (and
# any other USB instrument pyvisa-py talks to) to be visible to Python
# ==============================================================================
# Windows blocks direct USB access by default until a compatible driver is
# bound to the device. pyusb/libusb-package (below) need that access to talk
# to the signal generator over USB. Zadig is the tool that binds the right
# driver — it is NOT a Python package, so pip cannot do this step. It has to
# be run once, manually, per computer (and again if you move the instrument
# to a different USB port).
#
# 1. Google: "Zadig download" — or go directly to zadig.akeo.ie.
#    It's a single small executable (a few MB), no installer, nothing else
#    to download.
# 2. Plug in the signal generator and power it on BEFORE opening Zadig, so
#    it actually shows up in the device list.
# 3. Run the downloaded zadig-*.exe. Windows may show a SmartScreen warning
#    since it's a small unsigned utility — click "More info" > "Run anyway".
# 4. In Zadig, click Options > List All Devices (instrument-type USB
#    devices are hidden by default).
# 5. Open the dropdown at the top of the window and find the signal
#    generator. It may show up under its model name, as "USB Test and
#    Measurement Device", or as "Unknown Device". If more than one entry
#    looks related to it, repeat steps 5-7 for each one — one of them is
#    the right interface.
# 6. Make sure the box on the right (next to the green arrow) says
#    "WinUSB". If it shows something else, use the up/down arrows next to
#    it to select WinUSB specifically.
# 7. Click "Replace Driver" (it may say "Install Driver" the first time).
#    Wait for the progress bar to finish, then close Zadig. No reboot
#    needed.
#
# Once done, verify with (venv_physics active):
#   python -c "import usb.core; print(list(usb.core.find(find_all=True)))"
# An empty list [] or a NoBackendError means this step still needs fixing.
# See README.md Stage 8.5 for the full verification walkthrough.
